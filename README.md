# 🎓 College ERP - Attendance Management System

## 📌 Description

This project is a **College ERP Attendance Management System** developed using **HTML, CSS, and JavaScript**.
It helps in managing student attendance efficiently by allowing users to mark, track, and manage attendance records in a structured way.

The system provides a simple and user-friendly interface for handling attendance-related tasks digitally.

---

## ✨ Features

* ✅ Mark student attendance
* 📋 View attendance records
* ✏️ Edit and update attendance
* ❌ Delete records
* 📊 Organized data display
* 💾 Data stored using browser local storage
* 📱 Responsive UI for better usability

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## ▶️ How to Run the Project

1. Download or clone this repository
2. Open the project folder
3. Run the `index.html` file in your browser
4. Start marking and managing attendance
